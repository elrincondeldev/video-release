02Flujo release → vídeo

%%{init: {'theme':'base','themeVariables':{'fontFamily':'ui-monospace, monospace','fontSize':'13px','actorBkg':'#e6f1fb','actorBorder':'#185fa5','actorTextColor':'#042c53','signalColor':'#5a6b74','signalTextColor':'#23241f','noteBkgColor':'#faeeda','noteBorderColor':'#854f0b'}}}%%
sequenceDiagram
  actor Dev as Usuario
  participant GH as GitHub App
  participant API as Lambda API
  participant Q as SQS
  participant W as Fargate worker
  participant AI as Replicate
  participant APP as App desplegada
  participant S3 as S3
  Dev->>GH: publica una release
  GH->>API: webhook release (firmado)
  API->>API: valida firma + crea registro
  API->>Q: encola el job
  Q->>W: RunTask · escala 0 → 1
  Note over W: vCPU garantizada = fluidez
  W->>GH: lee notas + diff de la release
  W->>AI: genera el guion de la demo
  W->>APP: navega rutas + graba (cursor humano)
  W->>S3: sube el MP4
  W->>API: marca "listo" en la BD
  API-->>Dev: vídeo disponible para ver / descargar

Auth

Cognito — JWT validado en la API vía JWKS

GitHub

GitHub App — webhooks e installation tokens, sin config por repo

Escala

0 → N workers según la cola; API 100% serverless

Coste

Sin ALB ni NAT — API Gateway + subred pública

≈ $0 fijos en reposo · céntimos por vídeo · Terraform + Docker · IA en Replicate
